# Marisa shot-control candidate

`marisa.cpp` localizes nmlgc/ReC98
`b6ba5b0a529edbb31efdf8c0e939263804f8ee47`, `th05/p_marisa.cpp`, as natural
C++. It reuses the already declared real Shot and ShotAddIterator from
`reimu.hpp`; no existing type or accepted source is modified. Velocity setters
expand Subpixel's fixed-point assignments into ordinary signed `.v` stores.
X-before-Y and Y-before-X assignment macros retain their original ordering.

There are no instruction-emission directives, inline ASM, manually supplied
switch tables, synthetic linker symbols or asset arrays. Each table is to be
generated by the original semantic `switch` under the pinned compiler. The
original `#pragma option -a2` is retained as a real compiler input.
