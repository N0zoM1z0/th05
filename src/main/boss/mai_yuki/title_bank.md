# Semantic survivor-title field bank

This candidate models the four independently proved text objects as one near
semantic aggregate at original `[222E6,22334)`, 78 bytes. The fields preserve
their actual types and original order: const-character Yuki filename 10,
mutable unsigned-byte Yuki title 30, const-character Mai filename 10, and
mutable unsigned-byte Mai title 28. All four offsets and the total size are
asserted. There is no filler, explicit padding or changed constness.

This is a reconstruction grouping of related semantic objects, not a claim
that the historical source used a struct. It responds to actual native
compiler evidence: the prior four independent arrays produced correct
individual text but moved both mutable titles before both const filenames.
The failed original source, snapshots, OMF, MAP, MZ and receipt remain intact.
Private `.analysis/failed-semantic-text-data-review.json` records that outcome
and verifies both positive CP932 inputs and the exact archived negative.

Readable literals and actual original callback operands are unchanged from
the prior text review. Source stays UTF-8 and compiler staging uses CP932.
The ordinary aggregate has no CODE, BSS, pointer values, opaque initializer,
glyphs or asset payload. All 78 bytes and the empty original ordered-fixup
stream still require the normal complete DATA producer gates.

The explicit new source interface is `mai_yuki_title_bank` with fields
`yuki_dialog`, `yuki_bgm_title`, `mai_dialog` and `mai_bgm_title`. It does not
pretend to export the prior four array PUBDEFs. The unaccepted shared callback
may later use explicit field aliases in its affected closure. No accepted
header or caller has been changed.

The C++ aggregate producer stopped before an object was generated in
`main-mai-yuki-title-bank-a`: TCC rejects the const filename-array members
without constructors. No second producer or negative was run. Constness was
preserved; no constructor, compiler flag or emitted initialization code was
added. Its original source, snapshots and exact compiler log remain intact.

The current producer is instead `title_bank.c`, with the C-compatible
`title_bank_c.h` typedef-struct. Ordinary C static initialization preserves all
four actual member types and offsets without a constructor. A `__cplusplus`
error rejects accidental C++ mode. The wrapper also has a `.c` extension and
uses unchanged compiler arguments with no `-P`. Its explicit origin is
`compiler-generated-c-semantic-data`, available only for initialized DATA
with zero functions; it grants no compiler-generated CODE claim.

The independent outside-only binder retains DS `209D`, the real empty CODE
group context and DATA prefix `1916`. The own Mai title mutation remains
`少女` to `魔女`, with unchanged CP932 length. The focused C replay
`main-mai-yuki-title-bank-c-a` passed two fresh actual `.c` compiler producers,
all 78 raw bytes, the empty original ordered relocation stream and complete
OMF/MAP/input/tool/dependency checks. Its own compiled Mai-title mutation was
rejected. All 78 bytes were imported as authored C semantic DATA, separately
classified from C++ ownership. This accepts the explicit semantic model and
generated DATA, with no historical-struct claim, old-PUBDEF export claim or
transferred acceptance for any caller CODE.
